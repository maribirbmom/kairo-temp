# Kairo API

FastAPI backend for Kairo, a resume screener and CV coach. This file is the
Hugging Face Space config (the block above); the project overview is in the
repository root README.

Secrets (`GROQ_API_KEY`, `MONGO_URL`, `GOOGLE_CLIENT_ID`, `SESSION_SECRET`,
`CORS_ORIGINS`) are set in the Space settings, never in the code.
